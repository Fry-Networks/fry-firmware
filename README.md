# fry-firmware

Fry Networks embedded firmware for ESP8266/ESP32/ESP32-S3/ESP32-C3 - dVPN endpoint miners with OTA updates.

## Protocol

`PROTOCOL.md` is the byte-identical, shared contract with `fry-app-android`. Neither repo may
change it unilaterally.

## Build

```
pio run -e esp8266
pio run -e esp32
pio run -e esp32s3
pio run -e esp32c3
pio run -e esp32_lab      # esp32 + lab-only serial provisioning commands
pio run -e esp8266_lab    # esp8266 + lab-only serial provisioning commands
pio test -e native        # Unity tests (host, CI only)
```

`FRY_API_TOKEN` is read from the environment at build time by `tools/fry_prebuild.py` and baked
into `include/generated/fry_secrets.h`. It is optional; an empty token disables the build-time
bootstrap credential and registration falls back to per-device tokens only.

## Layout

- `include/config.h` — compile-time tunables, all `#ifndef`-guarded.
- `lib/fry_core/` — pure C++ modules with zero Arduino includes (provisioning state machine, OTA
  boot counter, SOCKS5 parser). Compiled by both the embedded envs and `pio test -e native`.
- `src/esp32/`, `src/esp8266/` — chip-specific provisioning transports and VPN endpoints.
- `test/test_provisioning/` — Unity tests for `lib/fry_core/`.
- `tools/` — host-side serial provisioning, capture, and QA gate scripts. CLI documented in
  `PROTOCOL.md` section 8.
- `ota/manifest.json` — generated by `tools/make_manifest.py`, consumed per `PROTOCOL.md` section 6.

## CI

`.github/workflows/build.yml` builds all four board environments plus the native Unity suite, and
attaches release binaries + a manifest on `v*` tags.
